Kestrel 4.2: result lines of the matches (fastchess through my_engine\match3.py: colours swapped, the same opening for both games of a round, 1 thread, Hash 64 (16 for the node-limited matches), no book, no learning, every engine process at full speed).
'Elo of A' is the first engine, with the 95 % interval of fastchess. 'nodes=N' = every move is searched to N nodes; '[adjudicated]' = games ended by a resign / draw rule (4 moves beyond 600 cp / from move 40 within 15 cp).
Names: ref41 = the packaged 4.1; ref16 = the 4.1 code with the rounded 8-bit network written back as 16-bit weights; i8 = the rounded network used as 8-bit rows (no fit of the output layers); cand1 = i8 + the fitted output layers + the correction history by the previous move;
v1 = cand1 + the faster evaluation kernels (the rows are copied into the permuted order when the network is loaded); v2 = v1 with the rows read in place from the KSTRNET4 file = the code of 4.2; qa = a fine-tune of the rounded network with the game labels (not used); ccm = the correction history by the previous move.
The release matches were run on the laptop that is also used for other things. A game that is played while another program loads the laptop ends by a time forfeit far more often (3.5 to 66 % of the games in the 14 five-minute windows that were dropped against 0 to 2.4 % in all the other windows; the 4.0 release match had 0.15 % over all of its games), and the draw rate falls. Rule (clean_gate_42.py, fixed before the final numbers were computed): the games are grouped by the 5-minute window in which they started; a window with at least 3 % time forfeits (and at least 3 forfeits) is 'disturbed' and all its games are dropped, whoever won; the dropped games are replayed in two extension matches (other openings, the same conditions). The 'clean' lines are the result of the games that are left; the raw lines of the matches show every game that was played.
