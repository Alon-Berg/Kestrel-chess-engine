Kestrel 5.0: result lines of the matches (fastchess through my_engine\match3.py: colours swapped, the same opening for both games of a round, 1 thread, Hash 64 (16 for the node-limited matches), no book, no learning, every engine process at full speed).
'Elo of A' is the first engine, with the 95 % interval of fastchess. 'nodes=N' = every move is searched to N nodes. Matches on a virtual clock (the vc50_ tags and the lines with nodes=100000000) use the engine's own clock counted in nodes (T_VNps 400 = 400,000 nodes per second), so their result does not depend on the load of the laptop.
Tags: rel50_ = the packaged final Windows x86-64-v3 exe of 5.0 (A) against the packaged exe of 4.2 (B), timed (the release matches); rel50r_ = the same with the REHEARSAL build of 5.0 (the values of SPSA iteration 210, no K41 macros, Move Overhead 5 unless the tag says mo10); r5f_ = the final values against the rehearsal values (fin1) and against the packaged 4.2 (fin3), 20,000 nodes per move; tm50_ / tmq_ = the time management (A = the new clock rule, B = the 4.2 rule in the same build); r5k_ = one change of the search (A) against the same development build without it (B), 20,000 nodes per move (the _s2 line is a second stage with other openings; 'pooled' values are in the notes); r5n_ = networks (A = the new network, B = the network of 4.2 in the same engine), 20,000 nodes per move; vc50_ = virtual clock.
The release matches were run on the laptop that is also used for other things. A game that is played while another program loads the laptop ends by a time forfeit far more often, and the draw rate falls. Rule (clean_gate_50.py, fixed before the final numbers were computed): the games are grouped by the 5-minute window in which they started; a window with at least 3 % time forfeits (and at least 3 forfeits) is 'disturbed' and all its games are dropped, whoever won; the other game of the same pair (same opening, colours swapped) is dropped too, so that the pairs stay complete, and no replacement games were played. The 'clean' lines are the result of the games that are left; the raw lines of the matches show every game that was played.
