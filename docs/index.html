Use it

  1. Download a file above and unzip it. Keep claude_book.txt next to the engine if you want the opening book (the book file keeps its old name).
  2. In your chess program, add a new UCI engine and point it at kestrel.exe. In Cute Chess this is Tools, Settings, Engines, the plus button.
  3. Set Hash to the memory you can spare and Threads to the cores you want to use.

Options include:

  • Hash, Threads (1 to 8)
  • MultiPV, Ponder
  • OwnBook, Experience
  • Move Overhead
  • UCI_LimitStrength, UCI_Elo
  • UCI_Chess960
  • UCI_ShowWDL, UCI_AnalyseMode
  • EvalFile, EvalScale (new in 2.0)

There is no Syzygy tablebase support.

How it works

The search is a conventional alpha-beta search with a transposition table. The new part in 2.0 is the evaluation: one network, in five stages.

  1. 24,576inputs per side: 12 piece kinds, 64 squares, 32 positions of the own king (mirrored)
  2. 1,536numbers per side, kept up to date move by move instead of recomputed
  3. 768products per side from the two halves of those numbers; about 90 % are zero
  4. 16 → 32 → 1three small layers, one of 8 weight sets chosen by the number of pieces
  5. centipawnsthe score the search uses
  • Training data. About 238 million positions from the Lichess evaluation database (Stockfish evaluations, CC0) and 12 million positions from Kestrel's own games, trained on the CPU with Adam. Stockfish only supplied labels; none of its code is in Kestrel.
  • Speed. A network this size costs time, so the evaluation code skips the zero inputs, builds the per-side numbers only for positions that are really evaluated, keeps a refresh cache for king moves and loads the weights ahead of time. Together that made the engine 1.95 times faster than its first version with identical moves and scores.
  • Beta. The network in beta 1 comes from about the middle of the planned training run. Training continues.

Build it yourself

The source is one file, src/kestrel_2_0.cpp. The 76 MB network is not stored in git: download kestrel_net_2_0_beta1.bin from the release, save it as kestrel_net.bin in the folder where you run the compiler, and compile.

g++ -std=c++17 -O3 -march=x86-64-v3 -static -pthread -DNDEBUG -o kestrel.exe src/kestrel_2_0.cpp

Other CPUs and operating systems: docs/BUILDING.md.
